# Galactic Defenders: control de calidad

Versión de [Galactic Defenders](https://github.com/romanvarela-rgv/galactic-defenders) que usé para la materia Control de Calidad de Videojuegos en UADE. Acá el juego pasa por un plan de pruebas y se corrigen los casos que fallaron.

*QA version of Galactic Defenders (Unity/C#): bug fixes from the test rounds plus new power-ups.*

## Qué hay en este repo

- **Correcciones** de los bugs que encontré al correr los casos de prueba, incluidos los que fallaron en la ronda v1.4.
- **Power-ups y drops**: los enemigos pueden soltar mejoras, entre ellas un misil teledirigido (`HomingMissile.cs`, `PowerUpPickup.cs`).

## Historial

| Fecha | Cambio |
|---|---|
| 31/05/2026 | Base del proyecto y primera ronda de bugs |

## Cómo abrirlo

1. Unity **2022.3.16f1**.
2. Abrí la carpeta desde Unity Hub.
3. Arrancá desde `Assets/Scenes/Menu.unity`.
